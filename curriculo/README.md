# Currículo

Fonte do currículo em PDF baixado pelo portfólio.

1. Edite `index.html` (abra no navegador para ver como fica).
2. Gere o PDF:

   ```bash
   npm run curriculo
   ```

   O arquivo vai para `public/Natanael-Ramos-Curriculo.pdf`, que é o link do botão "Baixar Currículo".
3. Faça commit do `index.html` e do PDF juntos.

O layout é uma página A4. Se o texto crescer demais, o fim da página é cortado: confira o PDF depois de gerar.
